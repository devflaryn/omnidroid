# D3a Guest Vulkan Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vulkan, and GLES through the image's ANGLE, work in a guest process on the host's GPU.

**Architecture:** `vulkan.omni.so` (guest, C, `hwvulkan` HAL) forwards each command through
`ioctl(/dev/omni-gpu, OMNI_GPU_CALL)` to `crate::gpu` (host, Rust), which calls the host driver;
most commands are generated from `vk.xml` 1.3.275 on both sides, the rest are hand-written.

**Tech Stack:** Rust + `ash` 0.38 (loading only), C (NDK r28c), Python 3 (generator), vk.xml 1.3.275.

**Spec:** `docs/superpowers/specs/2026-09-27-d3a-guest-vulkan-design.md`

## Interfaces fixed here (both sides depend on them)

Transport: `struct omni_gpu_call { u32 command; u32 argc; u64 args; u64 result; u64 reserved; }`
(32 bytes), `OMNI_GPU_CALL = 0xc0204701` (`_IOWR('G', 1, 32 bytes)`).

Guest wrapper of a dispatchable handle: `struct omni_vk_object { hwvulkan_dispatch_t dispatch; uint64_t host; }`.

Host (hand-written, `src/gpu/mod.rs`), used by generated code:
```rust
pub(crate) enum CallError { Args, Handle(u64), Missing(&'static str), Host(i32) }
pub(crate) struct Gpu { .. }                      // one per process
pub(crate) struct Table { .. }                    // one per host VkInstance / VkDevice
impl Gpu {
    /// The host handle behind a guest dispatchable wrapper, and the table its commands resolve in.
    pub(crate) fn dispatchable(&self, p: &Process, wrapper: u64) -> Result<(u64, Arc<Table>), CallError>;
}
impl Table {
    /// The host driver's entry point `name` (id `id`), resolved once.
    pub(crate) fn get(&self, id: u32, name: &'static std::ffi::CStr) -> Result<usize, CallError>;
}
// src/gpu/special.rs
pub(crate) fn call(g: &Gpu, p: &Process, id: u32, a: &[u64]) -> Result<u64, CallError>;
```
Generated host (`src/gpu/generated.rs`): `pub(crate) const ID_<SCREAMING_NAME>: u32` per command;
`pub(crate) const COMMANDS: &[(&str, u32 /*argc*/, bool /*special*/)]` indexed by id;
`pub(crate) fn dispatch(g: &Gpu, p: &Process, id: u32, a: &[u64]) -> Result<u64, CallError>` which
checks `a.len()` against argc, sends special ids to `special::call`, and calls generic ones.

Generated guest (`device/src/vk/generated.{c,h}`): `generated.h` declares every special entry
`omni_<vkName>` with its exact prototype (implemented by hand in `device/src/vk/special.c`) and the
table `extern const struct omni_vk_entry omni_vk_entries[]; extern const unsigned omni_vk_entry_count;`
with `struct omni_vk_entry { const char* name; PFN_vkVoidFunction fn; uint8_t level; /*0 global, 1 instance, 2 device*/ }`.
`generated.c` defines each generic entry `omni_<vkName>` packing its arguments and calling
`uint64_t omni_vk_call(uint32_t id, const uint64_t* args, uint32_t argc)` (hand-written, `driver.c`).

## Tasks

### Task 1: the transport (host) -- `/dev/omni-gpu` and `OMNI_GPU_CALL`
Files: `src/vfs.rs` (`DevNode::OmniGpu`), `src/fd.rs` (open, ioctl route), `src/gpu/mod.rs`,
`src/gpu/special.rs` (only `vkEnumerateInstanceVersion` for now), `Cargo.toml` (`ash`), test
`tests/gpu_transport.rs`: a test process opens `/dev/omni-gpu`, calls
`vkEnumerateInstanceVersion` (special id from a temporary hand constant) with a guest `u32*`, gets
`VK_SUCCESS` and a version >= 1.1; an unknown id and a short `argc` answer `EINVAL`.

### Task 2: the generator (agent)
Files: `tools/gen_vk_forward.py`, `tools/vk/vk.xml`, `tools/vk/SOURCE.txt`, outputs
`src/gpu/generated.rs`, `device/src/vk/generated.{c,h}`. Classification rules and the special list
are in the spec; the generator refuses unclassifiable commands; a Python unit test
(`tools/test_gen_vk_forward.py`) checks a few commands' generated text (a float parameter, a
dispatchable first parameter, a special command, a platform extension excluded).

### Task 3: the guest driver and the instance/device gate (`vkclear`)
Files: `device/src/vk/{driver.c,special.c,build.txt}`, built `device/vendor/lib64/hw/vulkan.omni.so`,
`src/device.rs`, `src/props.rs` (`ro.hardware.vulkan=omni`, `ro.hardware.egl=angle`),
`src/gpu/special.rs` (instance/device lifetime, enumeration, queues, command buffers, submit),
fixture `tests/fixtures/vkclear.c`, gate `tests/d3a_gpu.rs::vulkan_clears_an_image_on_the_host_gpu`.

### Task 4: ANGLE (`glclear`)
Fixture `glclear.c`; gate `angle_clears_a_pbuffer_on_the_host_gpu`. Whatever ANGLE asks that
Task 3 lacks (features, extensions, formats) is added in `special.rs`/generator classification.

### Task 5: gralloc on the GPU (`ahbrender`) and sync fds
`VK_ANDROID_native_buffer`, `VK_ANDROID_external_memory_android_hardware_buffer`, sync-fd
emulation, the content generation (mapper.c bumps it on unlock after a CPU write; rebuild).
Fixture `ahbrender.c`; gate `an_egl_image_on_a_gralloc_buffer_renders_where_the_host_reads_it`.
