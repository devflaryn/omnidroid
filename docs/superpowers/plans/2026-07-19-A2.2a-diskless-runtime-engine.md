# A2.2a — Diskless Runtime Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every instance diskless: boot the shared base `snapshot=on` with per-boot state in a throwaway `runtime/<username>/` directory, allocate ports **dynamically at launch** (freed when the instance stops), and pull account **identity from the central store** — removing the per-account `accounts/<name>/` folders and their persistently-stored ports and overlays. Existing commands (`start`, `play`, `stop`, `list`, `remove`) keep working through the new plumbing; the command-surface reshaping and session-from-store switch are A2.2b.

**Architecture:** Today an "account" is a folder `accounts/<name>/` holding `account.json` (base + statically-assigned ports + flags), plus (for non-ephemeral) COW overlays, plus a per-boot `efivars.fd` and `run.json`. The store (`accounts.py`, from A2.1) separately holds identity (username, cookie, place_id, base). A2.2a collapses this: **identity comes from the store**, **runtime state lives in `runtime/<username>/`** (efivars, `run.json` now carrying the dynamically-allocated ports + pid, `qemu.log`, autocap frames), and **every instance is ephemeral** (`snapshot=on`, no overlays). The universal `acct` dict that flows through `spawn_qemu`/`adb`/`deliver_session`/`_shutdown` keeps its exact key shape (`name`, `base`, `adb_port`, `qmp_port`, `vnc_port`, `ephemeral`, `dev`, `game_package`), so downstream consumers are unchanged — only how the dict is *built* and *where its files live* changes.

**Tech Stack:** Python 3.13+, QEMU (arm64/UEFI, `snapshot=on`), pytest/unittest.

## Global Constraints

- **The diskless invariant:** no per-account overlay disks and no persistent per-account folder. The only per-instance disk footprint is `runtime/<username>/` (efivars ~640KB + `run.json` + `qemu.log` + optional frames), created at launch and (A3) wiped on stop. Guest writes go to QEMU's `snapshot=on` `$TMPDIR` overlay, which QEMU auto-frees.
- **Identity is the store.** `base` (and later place/token) come from `accounts.py`. An instance can only launch for a username that exists in the store OR is being created by the launch itself (current `ensure_instance` auto-creates; A2.2a keeps auto-create but backs it by the store, not a folder).
- **Ports are dynamic, not stored on the account.** Allocated at launch from the config pool (`adb_port_start`/`qmp_port_start`/`vnc_port_start`) by scanning **running** instances; a stopped instance frees its slot. The aligned-triple invariant (same index for adb/qmp/vnc, ranges 1000 apart) is preserved.
- **One live instance per username.** `start` on an already-running username is rejected (unchanged behavior).
- **arm-only** (product is arm; dev is arm+devkit). The x86 overlay/first-boot/dexopt path is being retired here for instances (base-build commands in `baseimg`-land are out of scope).
- **`acct` dict key shape is preserved** so `spawn_qemu`, `adb`, `wait_for_boot`, `post_boot`, `deliver_session`, `_shutdown`, `qmp`, autocap, `account_status` need no change to how they *read* the dict.
- **No command-surface change in A2.2a.** `create`, `play`, `resume`, `start`, `stop`, `remove`, `session`, `list` still exist and still work. Deleting/merging commands and switching the session source to the store are **A2.2b**.
- **Suite stays green after every task** (currently 96). Tests that assert the *old* folder/overlay/static-port model are updated to assert the new diskless model in the same task that changes the behavior.
- **Run tests with:** `python3 -m pytest tests/ -q` from the repo root (`/Users/berat/Desktop/Omni Apps/omnidroid`).

```python
def allocate_ports(cfg):
    """Lowest free port-index across RUNNING instances (a stopped instance
    frees its slot immediately). The three ranges are 1000 apart, so the shared
    index keeps adb/qmp/vnc aligned and collision-free below 1000 concurrent."""
    q = cfg["qemu"]
    used = set()
    for inst in running_instances():
        if inst.get("adb_port") is not None:
            used.add(inst["adb_port"] - q["adb_port_start"])
    i = 0
    while i in used:
        i += 1
    return (q["adb_port_start"] + i, q["qmp_port_start"] + i,
            vnc_start(cfg) + i)
```
