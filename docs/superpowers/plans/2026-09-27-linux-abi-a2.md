# Linux kernel personality, milestone A2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The real AOSP `toybox ls -l /system/lib64`, `toybox cat /proc/self/maps` and `toybox ps -A` work: the last two show this process (its libraries, its stack, its pid and name).

**Architecture:** A `procfs` module generates `/proc` and `/sys` from the process's own state (the `Mm` file-mapping labels, `GuestSpace` regions, argv, tasks, the fd table). `vfs` reaches it through a `ProcFs` trait object attached after the process exists (no dependency from `vfs` on `process`), and `fd::open` snapshots a generated file into a new `FileKind::Synth` at open, as Linux's seq files read at open/first read.

**Tech Stack:** Rust, the A1 crate `omni-linux`.

**Spec:** `docs/superpowers/specs/2026-09-27-linux-abi-layer-design.md` (§1 milestone A2, §2 `vfs` row). Builds on the A1 plan `docs/superpowers/plans/2026-09-27-linux-abi-a1.md` (complete).

## Review Focus

1. **`/proc/self` is a symlink to the pid** on Linux (`readlink /proc/self` = `1000`); code that resolves `/proc/<pid>/...` must reach the same files as `/proc/self/...`. Test in Task 2.
2. **A generated file read in small pieces** (toybox reads `/proc/self/stat` with a 1 KiB buffer, `cat` with 4 KiB) must return the same bytes as one read, and `lseek(0)` must restart it. Test in Task 1.
3. **`/proc/self/maps` merges nothing it should not**: each file mapping keeps its own offset and path; anonymous regions get no path, the main stack is `[stack]`. Test in Task 2.
4. **`stat` of a `/proc` file answers size 0, mode 0444 regular**, as Linux does (toybox `ls -l /proc/self` must not fail). Test in Task 1.
5. **A pid that is not ours** (`/proc/1/stat`) is `ENOENT`, not our own data. Test in Task 2.

### Task 1: Generated files in `vfs` and `fd`

**Interfaces — Produces:**
- `procfs::ProcFs` trait: `fn node(&self, path: &[u8]) -> Option<Node>` (for any path under `/proc` or `/sys`), `fn list(&self, path: &[u8]) -> Vec<DirEnt>`, `fn read(&self, path: &[u8]) -> Option<Vec<u8>>`.
- `vfs::Node::Generated` (a regular file whose bytes come from `ProcFs::read` at open).
- `Vfs::attach_proc(&self, proc: std::sync::Weak<dyn ProcFs>)` (a `OnceLock` inside `Vfs`); `Vfs::lookup` routes `/proc`, `/proc/...`, `/sys`, `/sys/...` to it (falling back to the A1 static answers when nothing is attached, so A1 tests stay as they are); `Vfs::list` does the same; `Vfs::read_generated(&self, path) -> Option<Vec<u8>>`.
- `fd::FileKind::Synth { data: Vec<u8>, guest: Vec<u8>, pos: usize }`: `read`/`pread`/`lseek`/`fstat` work on it; writes are `EACCES`; `mmap` is `ENODEV`.

### Task 2: `/proc` and `/sys` for this process

**Files:** Modify `crates/omni-linux/src/procfs.rs`, `crates/omni-linux/src/process.rs` (attach at spawn and in `for_tests`; keep argv, the process name, the start time), `crates/omni-linux/src/mm.rs` (expose `file_mappings() -> Vec<(u64, u64, Vec<u8>, u64)>` and a `label_stack(start, len)`), `crates/omni-linux/src/fd.rs` (move `/proc/self/fd/N` into procfs as symlinks, list `/proc/self/fd`). Test `crates/omni-linux/tests/procfs.rs`.

**Interfaces — Produces:** `impl ProcFs for Process` answering:
- `/proc` (dir: `self`, `thread-self`, `<pid>`, `cpuinfo`, `meminfo`, `stat`, `uptime`, `loadavg`, `version`, `filesystems`), `/proc/self` and `/proc/thread-self` (symlinks to `<pid>` and `<pid>/task/<tid>`), `/proc/<pid>` (dir: `maps`, `smaps` absent, `stat`, `status`, `statm`, `cmdline`, `comm`, `exe`, `cwd`, `fd`, `task`, `limits`, `mounts`), `/proc/<pid>/task/<tid>` (dir: `stat`, `status`, `comm`), any other pid `ENOENT`.
- `maps`: one line per region from `GuestSpace::mapped_regions()`, in address order, `start-end perms offset 00:00 inode path`, perms from `Protection` with `p` (private) as the fourth letter, path from `Mm`'s labels (file path; `[stack]` for the main stack; nothing for anonymous).
- `stat` (52 fields, Linux's order; state `R`, ppid 1, pgrp/session = pid, utime/stime from the process clock in ticks of 100 Hz, starttime, vsize = mapped bytes, rss in pages), `status` (`Name`, `Umask`, `State`, `Tgid`, `Pid`, `PPid`, `Uid`/`Gid` ×4, `FDSize`, `VmSize`, `VmRSS`, `Threads`), `statm`, `cmdline` (argv, NUL-terminated each), `comm` (the task name or argv[0]'s basename, 15 bytes max, `\n`), `limits` (the `prlimit64` table), `mounts` (`/system`, `/apex/*`, `/data`, `/proc` lines).
- `/proc/cpuinfo` (one `processor : N` block per CPU from `sched_getaffinity`'s count, `Features : fp asimd aes pmull sha1 sha2 crc32` matching `exec::HWCAP`, `CPU implementer : 0x41`, `CPU architecture: 8`), `/proc/meminfo` (`MemTotal` 8 GiB per D36, `MemFree`, `MemAvailable`, zeros elsewhere), `/proc/stat` (`cpu` lines, `btime`), `/proc/uptime`, `/proc/loadavg`, `/proc/version` (`Linux version 6.1.0-omnidroid`).
- `/sys/devices/system/cpu/{possible,present,online}` = `0-N`, `/sys/devices/system/cpu` listing `cpu0..cpuN`, `possible`, `present`, `online`.

**Steps:**
- [ ] Tests first in `tests/procfs.rs` over `Process::for_tests` (which now attaches itself): `readlink /proc/self` = `1000`; `/proc/1000/cmdline` = `/proc/self/cmdline`; `/proc/1/stat` → `-ENOENT`; `maps` of a test process after mapping a sysroot file at offset 4096 contains `libx.so` with offset `00001000` and `r--p`; the 52-field `stat` parses (split after the `)`) with field 3 = `R`; `cpuinfo` lists `Features` with `asimd` and not `atomics`; `/sys/devices/system/cpu/possible` reads `0-N\n`.
- [ ] Run — FAIL. Implement. Run — PASS.
- [ ] Commit `feat(linux): /proc and /sys generated from the process itself`.
