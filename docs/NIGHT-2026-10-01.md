## Phase B core: `omni-debug` (emulation-layer debug engine) — landed on `mcp-server`

New crate `crates/omni-debug` (host-agnostic; no cfg(target_os), no OS crate). A `Session` loads a
library on the translating backend (per-thread cache so breakpoints are allowed — a shared cache
refuses them, D38) and exposes: resolve_symbol, list_symbols, list_maps, read_mem/read_words,
write_mem (forced write into RO code via COW + invalidate), dump_module, call_function (crafted
inputs), alloc_data + load_code (place a buffer / a code snippet), set_breakpoint/clear, run_until_stop
+ resume (interactive stepping), get_registers, backtrace (FP-chain walk), intercept (entry/exit +
replace_return), trace_calls, trace_syscalls.

Gate `crates/omni-debug/tests/lab.rs`, 12 tests, **all green on Windows**, driven against a checked-in
real AArch64 fixture (AOSP 15 `libz.so`, 117 KiB). call_function is checked against an independent
oracle (adler-32 computed in the test), not against zlib — the M2 rule.

Rulings made while building it (what / why / cost-if-wrong):
- **Driver resumes past a breakpoint by `run(from=bp_addr)`, not a manual single-step.** A manual
  `run(bp, Instructions(1))` overshoots to the end of the block (dynarmic counts per block) and can
  land silently on the *next* breakpoint, which the following `run` then suppresses (cpu.rs
  `suppressed_breakpoint`) — so an exit hook was missed. Using the backend's own suppress-and-resume
  fixed it. Cost if wrong: exit/trace events silently dropped.
- **call_function runs to completion (breakpoints are trace points via intercept); run_until_stop +
  resume is the interactive stepping path that pauses on user breakpoints.** Clear split; both service
  watches. Cost if wrong: confusing dual-purpose API.
- **Test targets: adler32 (perfect oracle) + zlibVersion (pointer) + crafted stubs.** compressBound
  was dropped as an oracle — this is **zlib-ng**, whose compressBound slack differs from stock zlib
  (got 4142 vs stock 4110 for 4096). adler32(NULL,0) and adler32's functable dispatch are skipped:
  the lab runs no init_array (needs the compat layer's imports), so functable pointers are null —
  a wild branch is a *typed* error (tested), never a host crash. Cost if wrong: brittle/false oracle.
