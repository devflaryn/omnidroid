## A note on BSL-1.0, which D3 does not name

D3 lists MIT / BSD / Apache-2.0 / ISC / 0BSD. Boost and Catch2 are **BSL-1.0**,
which is not on that list. BSL-1.0 is permissive and non-copyleft, and it is
weaker than MIT in the direction that matters here: it requires the notice only
when distributing *source*, and explicitly waives it for a compiled binary
("the notice requirement ... shall not apply to machine-executable object code
generated by a source language processor"). So it imposes strictly fewer
obligations than any licence D3 already accepts.

This is nonetheless a licence D3 does not name, and it arrived through an
undeclared dependency rather than a deliberate choice. It should be added to D3
explicitly. The alternative — patching `boost::icl` and `boost::variant` out of
dynarmic's IR terminal type and code-cache invalidation — is real work on the
component whose whole value is that it passes 202,200 assertions, and is not
worth doing to avoid a licence that asks less of us than MIT.
